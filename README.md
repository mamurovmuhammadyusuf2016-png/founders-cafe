# Founders Cafe — лендинг ☕

Одностраничный сайт кофейни **Founders Cafe** (Ташкент, ул. Алишера Навои, 11А).

## Что внутри

- **Hero** с фирменным фото и анимированным паром над чашкой (CSS-анимация)
- **3D-эффекты**: tilt-карточки, параллакс, глубина через `translateZ`
- **Меню** с Яндекс Еды — 10 категорий, табы с анимированным появлением карточек
- **Отзывы**: рейтинг 5.0 с Яндекс Карт, анимированные шкалы и счётчики
- **Контакты**: адрес, телефон, часы работы, Instagram, ссылка на Яндекс Карты
- Адаптив под мобильные, поддержка `prefers-reduced-motion`

## Стек

Чистые HTML / CSS / JS без сборки и зависимостей.
Шрифты: Playfair Display, Manrope, Caveat (Google Fonts, кириллица).

## Запуск

Просто откройте `index.html` в браузере, либо:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```
