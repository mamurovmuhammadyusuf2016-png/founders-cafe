# Founders Cafe — платформа заказов ☕

Онлайн-меню с корзиной для **Founders Cafe** (Ташкент, ул. Алишера Навои, 11А) в формате платформ доставки еды.

## Возможности

- **Каталог**: 11 категорий, ~55 блюд с фото (данные и фото — Яндекс Еда), сетка карточек с ценами
- **Корзина**: кнопка «+» / степпер количества на карточках, боковая панель корзины, плавающая кнопка на мобильных, сохранение в `localStorage`
- **Оформление заказа**: имя, телефон, доставка/самовывоз, адрес, комментарий → заказ формируется готовым сообщением, открывается в Telegram и копируется в буфер
- **Поиск** по блюдам, липкая лента категорий со scrollspy
- Обложка с фирменным фото и CSS-анимацией пара над чашкой
- Адаптив (мобильная сетка 2 колонки), поддержка `prefers-reduced-motion`

## Стек

Чистые HTML / CSS / JS без сборки и зависимостей.
Шрифты: Playfair Display + Manrope (Google Fonts, кириллица).

## Запуск

Просто откройте `index.html` в браузере, либо:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```
